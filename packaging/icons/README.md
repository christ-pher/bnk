# Icons

Everything Windows shows for bnk is drawn from one master, `bnk-logo.png`.

| Command | Writes |
|---|---|
| `python3 packaging/icons/gen.py` | `internal/trayicon/icons/*.ico`, `packaging/windows/bnk.ico`, `design/actual-size.png` |
| `sh packaging/icons/gen-syso.sh` | `cmd/{bnk,bnk-tray}/rsrc_windows_{amd64,arm64}.syso` |

Run them in that order — the resource objects are built from `bnk.ico`.
Outputs are committed, so the release build needs neither Pillow nor
`rsrc`. `gen.py` needs Pillow; `gen-syso.sh` needs Go and the network.

## Where each icon ends up

- **Tray** — `internal/trayicon` embeds the three state icons. The state
  is chosen by `trayui.Build`, not by the tray binary, so the mapping is
  tested on every platform rather than only on Windows.
- **Executables** — the `.syso` objects put the icon in `bnk.exe` and
  `bnk-tray.exe`, which is what Alt-Tab, the taskbar and Explorer read.
  They are per-arch because a COFF object names its machine.
- **Installer** — `packaging/windows/bnk.ico` is the MSI's
  `ARPPRODUCTICON` (the Add or Remove Programs entry) and the Start menu
  shortcut's icon.

## The design

The logo is nearly black, so at 16px on a dark taskbar it is a smudge,
and any colour-versus-greyscale distinction is unreadable. Three things
make the status legible anyway:

- the head is cropped square out of the head-and-chest portrait, so it
  fills the frame instead of shrinking to fit;
- the status dot is 34% of the icon and sits over the lower jaw, clear
  of the eyes and ears;
- the dot has a white outline, which separates it from both the black
  logo and either taskbar colour.

Green is connected and **disconnected has no dot at all**. Two dots
differing only in lightness is the one difference a 16px icon glimpsed
in the corner of a screen does not carry; dot-versus-no-dot is a
difference in shape, which it does.

Amber is "needs you" — the service is not running, or this machine has
not signed in. It stays a dot because it differs from green in hue
rather than lightness, and because it marks a state the user has to act
on and must not read as a deliberate disconnect. The menu has always
distinguished those two; the icon now does too.

Each `.ico` holds every size rendered at its own size rather than
downscaled from one large frame, because the small ones are what the
tray actually shows.

`design/` holds the review sheets: `actual-size.png` is the set at 1:1
on both taskbar colours and is regenerated by `gen.py`. The others
(`chosen-6x.png`, `treatments.png`, `crop-and-dot.png`) are a static
record of what was compared.
